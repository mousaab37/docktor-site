# Averin — Astro

A bright one-page site for a private clinic with family doctors, check-ups, a lab and specialists, in a single index.html plus an img/ folder. The demo clinic, Averin, its doctors, address, prices, numbers and reviews are fictional sample content.

Generated by the Formgong template generator from one source design. Live demo of the design: https://averin.formgong.com

## Set up the form

The contact form posts to `https://formgong.com/submit`. 

1. Create a form at https://formgong.com/new and copy its access key.
2. Open `src/content.json` and replace `fk_your_access_key` (under `form.access_key`) with that key. Every text of the page lives in the same file.
3. The form sends `access_key`, `subject`, `botcheck`, `service`, `name`, `email`, `phone`, `day`, `time`, `message`. The page shows thanks only when Formgong answers `success: true`.

## Run

```sh
npm install
npm run dev     # http://localhost:4321
npm run build   # static site in dist/
```

## Images

The photos were generated for this template (ChatGPT image generation, OpenAI). The places and people are fictional. Replace them with your own before launch.
