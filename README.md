# Doctor Website

Arabic RTL landing page for a single doctor, managed from a private dashboard (Astro + Cloudflare Workers + Supabase).

## Run

```bash
npm install --fetch-timeout=600000 --fetch-retries=5
npm run dev
npm run build
npm run check
```
